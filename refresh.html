📱 iPhone — Method A: Bookmark (try first)

  1. On ServiceNow page → tap Share (□↑) → Add Bookmark → name it SN Upload
  2. Tap Copy bookmark script below
  3. Safari → Bookmarks (book icon) → Edit → tap SN Upload
  4. Tap the URL field → delete all → Paste script → Done
  5. Go back to ServiceNow queue tab
  6. Tap Bookmarks → tap SN Upload
  7. Popup: ✅ Done or ❌ error

Do NOT paste in address bar — Safari blocks it.

📱 iPhone — Method B: Shortcuts app

  1. Install Shortcuts app (free, from App Store)
  2. Create shortcut → Add action Run JavaScript on Web Page
  3. Tap Copy Shortcuts code below → paste into that action
  4. On ServiceNow queue → tap Share → SN Upload shortcut

  1. Copy bookmark script above
